# Project Atlas Demo Guide (3–5 minutes)

1. Show the project structure and Docker Compose services.
2. Open the CI3 chat page and show the application.
3. Ask a market-size question as client C-01 and show the answer and citations.
4. Ask the same question as client C-02 and verify that unauthorized report figures are not disclosed.
5. Demonstrate conflicting report figures and explain the source scope.
6. Demonstrate a calculation and show the assumptions used.
7. Demonstrate a question that should be escalated to a human analyst.
8. Show the evaluation script and test results.
9. Briefly explain security, limitations, and future work.

Only present behaviors that have been tested successfully. Do not show API keys, passwords, or other secrets in the recording.
